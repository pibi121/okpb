| Услуга | Peaches | Когда |
|--------|---------|--------|
| Лукбук | **0** | лимит по пакету |
| Faceswap setup | **80** | 1× на персонажа |
| LoRA train | **1200** | старт трейна |
| 1 изображение | **6** | queue accept |

**Предохранитель Sprout:** видео из стартовых peaches — только после **5** картинок из гранта (или админ-флаг).
