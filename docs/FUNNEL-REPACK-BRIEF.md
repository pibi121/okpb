В связи с низкими конверсиями мы приняли решение изменить воронку бота, его технические возможности

Перед тем, как предоставлять пользователям новую версию проекта, нам нужно будет самостоятельно пройти всю новую воронку и убедиться в её правильности. Для этого нужно будет:

Сделать кодовое слово, которое после отправки открывает отдельно эту новую воронку так, будто мой аккаунт тг этот бот только запустил, у него нет работ, баланса и так далее, то есть открывается отдельное ответвление, а старая воронка перестаёт для этого аккаунта функционировать.
Сделать кодовые слова при отправке которых симулируется пополнение баланса. Суммы пополнения делаем те, что будут указаны дальше в техническом задании
Таким образом мы с нуля пройдём всю воронку, убедимся в ее работе и только после команды технического разработчика переносим воронку для всех пользователей

Старую воронку, функционал мы сохраняем на всякий случай, но для старых и новых пользователей будет действовать новая воронка. Те, кто уже есть в боте, увидят её после замены нажав на главное меню или перезапустив бота. Все напоминалки, рассылки и дожимы, кроме про оплаты, убираются

Все текста нужно переносить с учётом того форматирования, который есть в документа. Жирный, курсив, подчёркивание, эмодзи. 

Кнопки располагаются только в инлайн, внутри сообщений. Кнопка в чате меню только одна “Главное меню”. Кнопка “Студия” главная мини аппа переименовывается в PRO режим.
