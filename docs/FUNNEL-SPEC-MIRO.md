**Версия:** 0.1 (черновик для ручной доработки)  
**Источник:** Miro-схема воронки  
**Язык интерфейса:** русский  
**Валюта в UI:** персики 🍑 (в тексте подтверждения также показывать эквивалент в ₽ и $)

## 1. Принципы

1. Пользователь почти всегда ходит по **inline-кнопкам** под сообщением.
2. Где можно — **редактировать** то же сообщение бота (текст/подпись + кнопки), а не плодить новые. Исключения: результат генерации, антибан-пуш, статусы ожидания.
3. **Главное меню** — единый хаб. Каркас всегда один; меняется только «хвост» оффера (см. §5).
4. Для undress и видео хранится **одно активное фото** пользователя (можно сменить).
5. Списание / проверка баланса — на шаге **«Подтвердить»**.
6. **Триал:** первые **2** генерации без достаточного баланса можно сделать с **заблюренным** результатом; с **3-й** — только после пополнения.  
   *(Уточнить при доработке: только фото или и видео тоже.)*

## 2. Карта экранов

| ID | Экран |
|----|--------|
| A | Обложка + Старт |
| B | Правила / 18+ / оферта |
| C | Главное меню |
| C+ | Антибан (через ~30 сек) |
| D | Раздеть и сделать фото (выбор позы) |
| E | Подтверждение фото-шаблона |
| F | Ожидание генерации |
| G | Результат (полный) |
| Gblur | Результат с блюром (триал) |
| H | Доработка результата («добавь своё») |
| I | Горячее видео (выбор шаблона) |
| J | Подтверждение видео-шаблона |
| K | PRO режим |
| L | Баланс и пополнение |
| M | Заработать |
| N | Помощь |
| P | Запрос фото (нет активного фото) |
| Q | Недостаточно баланса |

```
A → B → C
         ├─ C+ (через ~30 сек, параллельно)
         ├─ D ⇄ P → E → F → G / Gblur → H?
         ├─ I ⇄ P → J → F → результат
         ├─ K
         ├─ L ← Q
         ├─ M
         └─ N
```

## 3. Экран A — Обложка + Старт

**Когда:** первый заход в бота (`/start`), правила ещё не приняты.

**Медиа:** красивая обложка / короткий ролик «что умеет бот» (пошаговый план).

**Текст сообщения:**  
*[плейсхолдер на схеме — зафиксировать копирайт вручную]*

Рекомендуемый черновик:

```
🍑 С PeachBitch ты воплощаешь фантазии без пластиковых «раздеваторов».

• Раздеть по 1 фото и поставить в любую позу
• Снять горячее видео по шаблону
• Собрать PRO-образ для максимального реализма

Жми Старт — и поехали.
```

**Кнопки:**

| Кнопка | Условие | Переход |
|--------|---------|---------|
| `Старт` | всегда | → B |

**Если** пользователь уже принял правила → A и B **пропускаются**, сразу → C.

## 4. Экран B — Правила и 18+

**Когда:** после «Старт».

**Текст:**

```
⚠️ Дальше ты воплощаешь все свои фантазии!

Но для этого нужно принять правила пользования ботом,
ознакомиться с офертой и подтвердить, что тебе есть 18 лет.

Просто нажми кнопку ниже.
```

В тексте — кликабельные ссылки: **правила**, **оферта**.

**Кнопки:**

| Кнопка | Переход |
|--------|---------|
| `✅ Принимаю правила и оферту` | сохранить согласие → C |

**Условия:**

- Без нажатия дальше по воронке нельзя.
- Повторный ввод текста/медиа до согласия → снова показать B (или коротко напомнить нажать кнопку).

## 5. Экран C — Главное меню

**Когда:**

- сразу после согласия с правилами;
- кнопка «Вернуться в главное меню» / «Назад» из подразделов;
- повторный `/start` у согласившихся.

**Медиа:** обложка «что умеет бот».

### 5.1 Текст (базовый)

```
Ну что, с чего начнём?

Твой баланс: {balance} 🍑

1. Раздеть по 1 фото, поставить её в любую позу 💦 и оживить
2. Сделать 🔥 видео с ней по 1 фото — секс, диалоги, сюжеты по готовым шаблонам
3. Сделать PRO образ твоего персонажа — новый уровень реализма и качества фото/видео в ⭐ PRO-режиме

🔗 Открыть примеры работ

Выбери, что тебя интересует по кнопкам ниже 👇
```

`🔗 Открыть примеры работ` — ссылка (лента / канал / галерея).  
*[Куда именно — зафиксировать вручную.]*

### 5.2 Хвост оффера (условие)

**Правило со схемы:** меню **всегда** такого каркаса, кроме **последнего предложения / хвоста**.

| Условие | Поведение хвоста |
|---------|------------------|
| Пользователь **ещё не** делал генерацию **и не** пополнял баланс | можно показать стартовый оффер (например про триал / «попробуй») — *[точный текст хвоста на схеме не зафиксирован]* |
| Уже была ≥1 генерация **или** было пополнение | стартовый хвост **убрать** / заменить на короткий нейтральный |

### 5.3 Кнопки

```
[ 💦 Раздеть и сделать фото 💦 ]
[ 🍓 Сделать горячее видео 🍓 ]
[ ⭐ PRO режим ]
[ 🍑 Баланс и пополнение ]
[ 🤑 Заработать ] [ ℹ️ Помощь ]
```

| Кнопка | Переход |
|--------|---------|
| `💦 Раздеть и сделать фото 💦` | → D |
| `🍓 Сделать горячее видео 🍓` | → I |
| `⭐ PRO режим` | → K |
| `🍑 Баланс и пополнение` | → L |
| `🤑 Заработать` | → M |
| `ℹ️ Помощь` | → N |

## 6. Экран C+ — Антибан (~30 секунд)

**Когда:** примерно через **30 секунд** после показа главного меню.  
*[Уточнить: один раз за жизнь аккаунта / раз в N дней.]*

**Текст:**

```
Telegram блокирует такие боты.

Чтобы не потерять нас — сохрани наш чат коммьюнити
и вечную ссылку на актуального бота.
```

**Кнопки:**

| Кнопка | Действие |
|--------|----------|
| `Открыть коммьюнити` | ссылка на чат сообщества |
| `Актуальный бот` | вечная ссылка / зеркало |

Это **отдельное** сообщение, хаб не ломает.

## 7. Экран D — Раздеть и сделать фото

**Когда:** кнопка undress из главного меню.

### 7.1 Текст — ветвление по фото

**Если активного фото нет:**

```
Фотография пока не загружена.

Загрузи фото девушки и выбери шаблон —
сделай с ней всё, что захочешь 😈
```

Параллельно: состояние «ждём фото» (экран P), либо явное предложение прислать фото.

**Если активное фото есть:**

```
Фотография загружена, но ты можешь заменить её на другую.

Просто выбери шаблон и сделай с ней всё, что захочешь 😈
```

Желательно показать превью текущего фото.

### 7.2 Кнопки

```
[ Раздеть полностью ]
[ Поза 1 ] [ Поза 2 ]
[ Поза 3 ] [ Поза 4 ]
[ Поза 5 ] [ Поза 6 ]
[ Ещё шаблоны ➡️ ]
[ Сменить фото ]
[ ⬅️ Вернуться в главное меню ]
```

| Кнопка | Условие | Переход |
|--------|---------|---------|
| `Раздеть полностью` | есть фото → E; нет фото → P (запомнить шаблон) | |
| `Поза 1`…`Поза 6` | то же | → E или P |
| `Ещё шаблоны ➡️` | всегда | следующая страница шаблонов (тот же экран D) |
| `Сменить фото` | всегда | → P, потом обратно в D |
| `⬅️ Вернуться в главное меню` | всегда | → C |

**Логика:** сетка поз — страница каталога; «Ещё шаблоны» листает дальше. «Раздеть полностью» — выделенный (featured) шаблон сверху.

## 8. Экран P — Запрос фото

**Когда:**

- пользователь выбрал шаблон, но фото нет;
- нажал «Сменить фото».

**Текст:**

```
Пришли одно фото девушки в этот чат.

Лучше анфас или в полный рост, без сильных фильтров.
```

**Кнопки:**

| Кнопка | Переход |
|--------|---------|
| `⬅️ Назад` | → D (или I / C — откуда пришли) |

**После получения фото:**

1. сохранить как активное;
2. если был выбран шаблон → сразу **E** (или **J** для видео);
3. иначе → обратно в **D** / **I**.

---

## 9. Экран E — Подтверждение фото-шаблона

**Когда:** выбран шаблон undress **и** есть активное фото.

**Медиа:** обложка позы (GIF / короткое видео / превью).

**Текст:**

```
📖 {описание_позы}

Стоимость: {цена_персики} 🍑 ({цена_руб} ₽ / {цена_usd}$)

🔗 Инструкция, как использовать шаблон и примеры
```

**Кнопки:**

| Кнопка | Переход |
|--------|---------|
| `Отменить` | → D |
| `Подтвердить ✅` | см. условия ниже |

### 9.1 Условия после «Подтвердить»

| Условие | Действие |
|---------|----------|
| Баланс ≥ стоимости | списать → **F** → **G** (полный результат) |
| Баланс < стоимости **и** триал-счётчик < 2 | триал +1 → **F** → **Gblur** |
| Баланс < стоимости **и** триал-счётчик ≥ 2 | → **Q** (недостаточно), затем пополнение **L** с возвратом на E |

---

## 10. Экран F — Ожидание генерации

**Текст:**

```
Оу, сейчас я буду творить!
Мне нужно немного времени — скоро пришлю результат.
```

Кнопки на схеме не обязательны. Можно ничего не показывать или дать «В главное меню» (не отменяет уже запущенную генерацию — уточнить вручную).

## 11. Экран G — Результат (полный)

**Медиа:** готовое фото (или видео — в видео-ветке).

**Текст:**

```
Готово! Как тебе? 🔥
```

**Кнопки** (рекомендуемый набор — на схеме частично):

| Кнопка | Переход |
|--------|---------|
| `Другая поза` / `Ещё фото` | → D |
| `Сделать видео с этим фото` | → I (то же активное фото) |
| `Добавить что-то своё` | → H |
| `⬅️ В главное меню` | → C |

---

## 12. Экран Gblur — Результат с блюром (триал)

**Медиа:** тот же результат, **заблюренный**.

**Текст** (черновик — на схеме логика есть, копирайт уточнить):

```
Готово! Это превью 🔥

Полный кадр без блюра откроется после оплаты.
Осталось бесплатных превью: {2 − использовано}.
```

**Кнопки:**

| Кнопка | Переход |
|--------|---------|
| `🍑 Пополнить и открыть` | → L (после оплаты — отдать полный файл / возврат к генерации) |
| `Другая поза` | → D |
| `⬅️ В главное меню` | → C |

---

## 13. Экран H — «Добавь своё» (после результата)

**Текст:**

```
Хочешь добавить что-то своё на её тело?
Татуировку, изменить волосы, увеличить/уменьшить грудь?

Напиши, что изменить — одним сообщением.
```

**Кнопки:**

| Кнопка | Переход |
|--------|---------|
| `⬅️ Назад к результату` | → G |
| `В главное меню` | → C |

**После текста пользователя:** подтверждение стоимости (как E) → F → новый результат G.  
*[MVP или нет — решить вручную.]*

## 14. Экран I — Горячее видео (выбор шаблона)

**Когда:** кнопка видео из главного меню.

Логика **зеркальна undress**, с видео-шаблонами (сюжеты, диалоги).

**Текст** (черновик):

```
Выбери шаблон горячего видео 🔥

Нужно всего 1 фото. Если фото уже загружено —
можешь сразу выбрать сюжет. Если нет — попросим прислать.
```

**Кнопки:**

- сетка шаблонов (название / превью-кнопки);
- `Ещё шаблоны ➡️`;
- `Сменить фото`;
- `⬅️ Вернуться в главное меню`.

| Есть фото? | Выбор шаблона ведёт в |
|------------|------------------------|
| да | → J |
| нет | → P (запомнить шаблон) → J |

## 15. Экран J — Подтверждение видео

**Медиа:** превью шаблона (GIF / видео).

**Текст:**

```
📖 {описание_сюжета}

Стоимость: {цена_персики} 🍑 ({цена_руб} ₽ / {цена_usd}$)

🔗 Примеры и инструкция
```

**Кнопки:**

| Кнопка | Переход |
|--------|---------|
| `Отменить` | → I |
| `Подтвердить ✅` | те же правила баланса / триала, что в §9.1 → F → результат (видео) |

**Опционально** (если в шаблоне есть речь): перед confirm спросить  
`Что ей сказать? (или нажми Пропустить)` — *[на схеме намёк есть, экран не детализирован]*.

## 16. Экран K — PRO режим

**Когда:** кнопка `⭐ PRO режим`.

**Медиа:** стильная обложка PRO.

**Текст:**

```
⭐ PRO режим — новый уровень удовольствия, реализма и качества.

Создай PRO-образ персонажа один раз —
и генерируй максимально качественные фото и видео
с одним и тем же лицом и телом.
```

**Кнопки:**

| Кнопка | Действие |
|--------|----------|
| `Открыть ленту` | открыть ленту работ / шаблонов (мини-приложение или ссылка) |
| `Создать PRO образ` | мастер создания персонажа / образа |
| `Как это работает?` | короткий гайд (отдельное сообщение или статья) |
| `⬅️ Вернуться в главное меню` | → C |

**Смысл ветки:** высокий реализм за счёт заранее собранного персонажа; дальше генерации идут «от образа», а не только от одного фото.

## 17. Экран L — Баланс и пополнение

**Когда:** кнопка с хаба или из экрана Q.

**Текст** (каркас):

```
Твой баланс: {balance} 🍑

Выбери пакет для пополнения:
```

Далее — список пакетов (цены / бонусы — отдельная таблица прайса, на схеме не расписана).

**После успешной оплаты:**

- если пользователь пришёл из confirm (E / J) → вернуть на тот confirm;
- иначе → C.

## 21. Сводка условий (шпаргалка)

| Ситуация | Поведение |
|----------|-----------|
| `/start`, правила не приняты | A → B → C |
| `/start`, правила приняты | сразу C |
| Нет фото + выбран шаблон | P → затем confirm |
| Есть фото + выбран шаблон | сразу confirm |
| Confirm + хватает баланса | полная генерация |
| Confirm + не хватает + триал < 2 | блюр-результат |
| Confirm + не хватает + триал ≥ 2 | экран Q → пополнение |
| ~30 сек после хаба | антибан-пуш C+ |
| Уже генерил или пополнял | у хаба другой / пустой хвост оффера |
