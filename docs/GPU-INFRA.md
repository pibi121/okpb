# GPU-инфра Peach — поставщики, RunPod, идеальная схема

**Статус:** черновик для возврата (2026-08-17)  
**Не утверждено как прод-контракт** — зафиксировано после разбора масштаба.  
Связано: [`ECONOMICS-APPROVED.md`](ECONOMICS-APPROVED.md)

Стек на карте: **RTX 5090 32GB**, Comfy (Krea still + MiniMax I2V + ACE-Step).  
LLM (Gemma 4 31B ~24 GB) **не держать одновременно** с Comfy на одной 5090.

Курс в расчётах: **~80 ₽ / $**. Тайминги: still ~25 с, клип 5 с ~3.5 мин, LoRA ~2 ч.

## 1. База сейчас

**Metalnode** — выделенная 5090, оплата рублями, ~**55 ₽/час**. Удобно для R&D.  
Минус: маленький парк, витрина может быть пустой, нет запаса «ещё 4 карты завтра».

## 2. Три поставщика (shortlist)

### HOSTKEY — основной заменитель Metalnode (always-on)

| | |
|--|--|
| Что | Dedicated 5090 в нормальном ДЦ, root/SSH |
| Цена | от **~45 900 ₽/мес** (~62 ₽/час) или **€449/мес** (hostkey.com) |
| Стабильность | TIER III, аптайм ~99.98% |
| Объём | реальный парк, 1–N карт, NL / IS / RU / FI |

**Оплата**

- **hostkey.ru, рубли:** МИР, СБП, SberPay, T-Pay, ЮMoney, российские Visa/MC, счёт юрлицу. ЮKassa только с **российского IP** (VPN выключить).
- **hostkey.com:** Stripe-карты, PayPal, перевод, **BitPay: BTC, ETH, USDT, USDC** (USDT обычно **ERC-20**). Для крипты — BitPay ID (KYC).

Минус vs Metalnode: чуть дороже час. Плюс: можно взять 2–4 карты без «найдите ещё Metalnode».

### RunPod — очередь и масштаб воркеров

| | |
|--|--|
| Цена | Community **$0.69/ч** (~55 ₽), Secure **$0.99/ч** |
| Объём | большой каталог 5090, API, секундный биллинг |
| Диск | Network Volume **$0.07/GB/мес** (<1 ТБ) — **только Secure Cloud** |

**Оплата:** карты Stripe, **крипта** (KYC на первый платёж), инвойс от **$5k**. **Рублей нет.**

Community: дешевле, хосты третьих лиц, **нет жёсткого SLA**, обрыв I2V = сожженный peach.  
Secure: прод-очередь. Stopped pod: volume disk **$0.20/GB/мес** (штраф) — terminate + Network Volume, не «стоп и забыть».

### Vast.ai — минимум цены, только burst / LoRA

| | |
|--|--|
| Цена | on-demand **~$0.34–0.50/ч**; reserved до **−50%** предоплатой |
| Стабильность | **нет SLA платформы**. Только **Verified Datacenter**, высокий рейтинг |
| Оплата | Stripe; крипта **BitPay / Crypto.com**. Крипто-кредиты не рефанд. Без карты на бэкапе при $0 **сносят инстанс и диск** |

**Не брать как основу:** Immers.cloud (~131 ₽/ч), Salad (чужие ПК, преэмпт).

## 3. Всё на RunPod — можно ли

**Да, для 10 и 100 человек это не блокер.** Проблемы не в цене, а в always-on и обрывах.

Что ок: 5090 есть, API, несколько воркеров, оплата криптой как у юзеров.

Что болит:

1. **Простой дороже полезной работы.** MiniMax нельзя каждый раз грузить с нуля (~63 ГБ). Под **24/7**, даже если тестеры спят. У 10 человек утилизация ~2–8%.
2. **Network Volume только на Secure.** Community: диск привязан к поду; хост умер — настройка заново.
3. **Community без SLA** — обрыв на 4-й минуте I2V.
4. **Одна 5090 ≠ Comfy + Gemma сразу.** 10–100: timeshare (выгрузить Ollama перед видео). 1000: отдельная очередь LLM или вторая дешёвая карта.
5. **NSFW / ToS** — не единственный бэкап весов.
6. **Нет ₽.**

Для закрытой беты — один вендор ок. С 1000 — не Community и не один под.

| **1000 юзеров** | Sprout-гранты + ~8% платящих, пик вечером | **2×5090 Secure** + LoRA по запросу | ~$1 050 (рискованно) | **~$1 500–1 650** (~120–132 тыс. ₽) |

Разложить на RunPod:

| Этап | Что поднять |
|------|-------------|
| 10 | 1 под Community, модели на диске пода, LLM timeshare, **не гасить** под |
| 100 | тот же 1 под, но **Secure + Network Volume** (~$18/мес за 250 ГБ) |
| 1000 | 2 воркера Secure на одном volume + 3-й под только на LoRA |

**Маржа на 1000 MAU:** при ~80 платящих GMV ~$4k, GPU ~$1.5k → **~35% выручки**, выше цели 14%. 14% сходится ближе к сотням платящих и 2–4 **загруженным** картам, не к 1000 MAU с 8% CR. На ранних этапах вы платите за простой, не за джобы.

Выключить на ночь: −30–40% денег, но холодный MiniMax убивает UX — для беты не надо.

## 5. Идеальная схема распределения (к чему идём)

Не один вендор навсегда. Три слоя, роли не смешивать.

```
Юзеры Peach
    │
    ▼
Очередь jobs (still / I2V / music / LoRA)
    │
    ├─ ALWAYS-ON  ── HOSTKEY 1–2×5090
    │                 прод Comfy, тёплый MiniMax, рубли как сейчас
    │
    ├─ SCALE      ── RunPod Secure N воркеров + Network Volume
    │                 пик вечером, API, те же веса
    │
    └─ BURST      ── Vast.ai Verified Datacenter
                      только LoRA (~2 ч) и переполнение видео
```

### Слой A — always-on (HOSTKEY)

- 1 карта на старте (как Metalnode), со 100 активных — вторая.
- Тёплый MiniMax + Krea. Не гасить.
- LLM: timeshare на этой карте **или** отдельный дешёвый CPU/маленький GPU позже.
- Оплата: рубли (СБП/МИР) или USDT через BitPay на .com.
- Metalnode: держать как **запас**, пока веса не перенесены; не строить на нём парк.

### Слой B — scale (RunPod Secure)

- Не заменять HOSTKEY, а **добавлять воркеры**, когда очередь > N минут.
- Один Network Volume на регион, все поды монтируют его (модели один раз).
- 1000 юзеров: **2 воркера** вечером; днём можно 1.
- Community — только свои тесты, не юзерская очередь.

### Слой C — burst (Vast.ai)

- LoRA **никогда** на always-on (2 часа блок видео).
- Отдельный инстанс на время трейна, Verified Datacenter, предоплата/карта-бэкап.
- Interruptible — только если джоба умеет рестарт.

### По этапам продукта

| Этап | Идеал | Допустимый shortcut |
|------|--------|---------------------|
| **10 тестеров** | **Metalnode 1×** (не трогать) | — |
| 100 фокус | HOSTKEY 1× **или** Metalnode, если ещё тянет | RunPod **Secure** 1× + volume |
| 1000 | HOSTKEY 1–2× + RunPod 1–2 воркера + Vast под LoRA | RunPod-only 2× Secure |
| Путь к $10k прибыли (~240–270 платящих) | HOSTKEY 1–2× + RunPod пик + Vast | 4× Secure RunPod |

**10 тестеров — оставляем Metal (рекомендуется).**  
Цена ~**55 ₽/ч** × 730 ч ≈ **40 150 ₽/мес** (~**$502** при 80 ₽/$). App/S3 ~$20 → **всего ~$520–530/мес**.  
Vs HOSTKEY (~45 900 ₽ / $574): Metal дешевле на ~**5–6 тыс. ₽** (~$70). Полезной работы ~16 ч — почти весь счёт за простой; переезд ради $70 бессмыслен. LoRA/видео на той же карте (timeshare с LLM). RunPod/Vast не подключать.

**Если неделя тестов каждый день (10 чел), не месяц:**

| Режим | Часы | ₽ (≈55 ₽/ч) | $ (80 ₽/$) |
|--------|------|-------------|------------|
| **24/7 всю неделю** (тёплый MiniMax) | 7×24 = **168 ч** | **~9 240** | **~$115** |
| День 12 ч × 7 (ночью гасить) | **84 ч** | **~4 620** | **~$58** |
| Только «когда кто-то жмёт» ~6 ч/день | **42 ч** | **~2 310** | **~$29** |

Рекомендация на неделю: **24/7 (~9.2 тыс. ₽ / ~$115)** — иначе каждый день холодный MiniMax (минуты на прогрев) и злые тестеры. App на неделю копейки (~$5).  
Интенсивность 10 чел × 7 дней: порядка **4–12 полезных GPU-ч** (картинки + клипы + 0–1 LoRA) — всё равно внутри одной карты; узкое место не ёмкость, а удобство очереди вечером.

Когда уходить с Metal: нет свободной карты / нужен 2-й воркер / старт фокуса 100 с публичной очередью / хотите зафиксировать HOSTKEY до роста.

### Деньги vs риск (зачем не всё на RunPod навсегда)

| | Всё RunPod | Идеал (HOSTKEY + RunPod + Vast) |
|--|------------|----------------------------------|
| 10 чел | проще, ~$530–740 | почти те же деньги, рубли |
| 1000 | ~$1.5–1.7k, один ToS, нет ₽ | HOSTKEY фикс + RunPod только пик — меньше простоя на дорогом Secure |
| Сбой вендора | очередь мертва | перекинуть jobs на второй слой |
| LoRA | блокирует видео или третий под | Vast дешевле, видео не стопорит |

**Правило:** прод-очередь (картинка/клип) — только dedicated или Secure. Дешёвый маркетплейс — только обучаемые/повторяемые джобы.
