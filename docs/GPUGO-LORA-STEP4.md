# LoRA в ComfyUI на GPUGO — пункт 4 (куда нажимать)

Ты уже: фото + подписи + расширение. Ниже только **запуск обучения**.

> Важно: пакет **Lora-Training-in-Comfy** лучше работает с SD 1.5.  
> У тебя **Pony (SDXL)** — если train упадёт с ошибкой, пиши текст ошибки: перейдём на встроенный **Train LoRA** или kohya.

---

## A. Подготовь папку датасета (обязательно)

Расширение ждёт имя папки вида: **`число_имя`**.

В Jupyter Terminal:

```bash
# если фото лежат в char1 — переименуй папку
mv /workspace/datasets/char1 /workspace/datasets/10_olh_person

# проверка: внутри картинки + txt
ls -la /workspace/datasets/10_olh_person | head
```

Итог:
- путь к фото: `/workspace/datasets/10_olh_person/`
- родитель (это важно): `/workspace/datasets`

Trigger в `.txt` должен быть тот же, что потом в промпте, например `olh_person`.

---

## B. Новый пустой граф в ComfyUI

1. Открой ComfyUI.  
2. Сверху **Граф → Clear / Очистить** (или новый workflow), чтобы не мешала схема генерации.  
3. ПКМ по чёрному полю → **Добавить узел**.

---

## C. Найди ноду обучения

Варианты поиска (двойной клик по холсту часто открывает поиск):

- набери: `Training` или `LoRA` или `LJRE`
- или меню: категория **LJRE** / **LORA**

Нужна нода вроде:
- **Lora Training**  
- или **Lora Training Advanced**

Добавь **одну** эту ноду на холст.  
Другие ноды для этого пакета обычно **не нужны** — всё внутри одной карточки.

---

## D. Что вписать в поля ноды

| Поле (как может называться) | Что поставить |
|-----------------------------|---------------|
| **data_path** / путь данных | `/workspace/datasets` ← **родитель**, НЕ `10_olh_person` |
| **ckpt_name** / checkpoint | `ponyDiffusionV6XL_…safetensors` (твой Pony) |
| **output_name** / имя LoRA | `olh_person_lora` |
| **steps** / max train steps | `1500` |
| **network_dim** / rank | `16` |
| **learning_rate** | оставь по умолчанию или `0.0001` |
| **resolution** | `1024` если есть |
| **batch_size** | `1` |

Если есть выпадающий список моделей — выбери Pony из списка, путь к ckpt может заполниться сам.

---

## E. Запуск

1. Сверху синяя **«Запустить»** (Queue).  
2. Внизу должна пойти очередь / прогресс.  
3. **Ничего не останавливай** 1–2 часа.  
4. Можно смотреть логи в терминале Jupyter, если нода пишет туда.

Готово, когда появится файл:

```bash
ls -lh /workspace/models/loras
```

Ищи `olh_person_lora.safetensors` (или похожее имя).

---

## F. Если ноды LJRE нет после установки

1. **Управление расширениями** → вкладка **Установлено** → есть ли `Lora-Training-in-Comfy`.  
2. Перезапуск бэкенда / F5.  
3. В терминале:

```bash
ls /workspace/custom_nodes | grep -i lora
```

Если папки нет — установка не завершилась. Напиши, что показал `ls`.

---

## G. Тест после обучения (пункт 5)

1. Верни схему генерации (checkpoint Pony + KSampler…).  
2. Добавь ноду **Load LoRA** / «Загрузить LoRA».  
3. Выбери `olh_person_lora`, strength **0.8**.  
4. В positive в начале: `olh_person, …`  
5. Три картинки → сравни лицо с фото.

---

## Если train сразу ошибка

Пришли **точный текст** красной ошибки. Частые случаи:
- неверный `data_path` (указал папку с фото вместо родителя);
- Pony/SDXL не поддерживается этим пакетом → другой способ;
- нет `.txt` рядом с картинками.
