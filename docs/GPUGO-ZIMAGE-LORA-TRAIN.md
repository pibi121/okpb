# Character LoRA на Z-Image (своё лицо) — GPUGO

Стек инференса у тебя: **Z-Image Turbo** в ComfyUI All-in-One.  
Старая Flux-LoRA (`olh_person_flux…`) **сюда не подходит** — учим **новую**.

Тренер: **Ostris AI Toolkit** + **training adapter** для Turbo  
(без адаптера Turbo «ломается» и перестаёт быть быстрым).

---

## 0. Что нужно от тебя сейчас

1. GPUGO инстанс **Running** (сейчас SSH мог не отвечать — проверь панель).
2. **15–30 фото** лица (лучше 20+):
   - разные ракурсы, свет, одежда, фон;
   - лицо крупно / средне;
   - без сильных фильтров, без чужих watermark;
   - желательно квадрат или близко к 1:1, не крошечные превью.
3. Trigger-слово (одно, редкое): **`olh_person`**  
   (можешь другое латиницей, но потом везде одинаково).

**Не нужно:** скачивать character-LoRA с Civitai.  
**Нужно:** свои фото → обучение → свой `.safetensors`.

---

## 1. Как залить фото на GPU

### Вариант A — Jupyter (проще для новичка)
1. Открой Jupyter GPUGO (порт **8888**).
2. Создай папку: `datasets/olh_person_zimage/images/`
3. Загрузи туда все фото (Upload).
4. Напиши мне: «фото залиты».

### Вариант B — я помогу скриптом
Положи фото локально, например:
`./datasets\olh_person_zimage\`  
и в Agent mode скажи «залей датасет» — залью по SSH/SFTP.

---

## 2. Подписи (captions)

На каждое фото — файл с тем же именем и расширением `.txt`.

Пример: `01.jpg` → `01.txt` с текстом:

```text
olh_person, woman, looking at camera, soft light
```

Минимум в каждой подписи: **`olh_person`**.  
Остальное коротко по кадру (поза, свет, одежда) — на английском.

Если подписей нет — можно стартовать с одной строки `olh_person` на все (хуже, но для теста лица ок). Потом улучшим.

---

## 3. Параметры обучения (стартовый пресет)

| Параметр | Значение | Зачем |
|----------|----------|--------|
| База | `Tongyi-MAI/Z-Image-Turbo` | совпадает с твоим флоу |
| Adapter | `zimage_turbo_training_adapter_v1` | не ломает Turbo |
| Steps | **2000–3000** | character, короткий прогон |
| LR | **1e-4** | стандарт Ostris |
| LoRA rank | **16** | лицо; при OOM → 8 |
| Resolution | 512/768 (bucket), осторожно с 1024 | VRAM |
| Batch | 1 | стабильно |
| Save every | 250–500 | выбрать эпоху глазами |
| Имя выхода | `olh_person_zimage` | файл LoRA |

Сэмплы во время трейна: промпт вида  
`olh_person, portrait, natural light` на 8 steps.

После обучения адаптер **не нужен** в Comfy — только твоя LoRA на Turbo.

---

## 4. Как потом вставить в All-in-One

1. Файл: `models/loras/olh_person_zimage.safetensors` (или checkpoint эпохи).
2. Нода **Lora Loader Stack**:
   - `lora_01` = этот файл  
   - strength начни **0.6–0.85**  
   - остальные слоты **None**
3. В positive в начале: `olh_person, ...`
4. Сравни: без LoRA / 0.6 / 0.8 / 1.0.
