## 5. GPU elastic scaling

- **BASE:** 1× Metalnode always-warm
- **BURST:** RunPod + Network Volume (не копировать 63 GB каждый раз)
- **Scale-up:** `queue_depth > 2×workers` OR `wait_p95 > 70% SLA`
- **Pre-warm:** за 15–30 мин до пика (19:00)
- Cold start цель: **10–15 мин** (golden image + shared volume)
