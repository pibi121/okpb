## Про «куки» (вопрос 14)

Это не browser cookie, а **привязка юзера к партнёру навсегда**:

1. Юзер кликает `t.me/peachbibot?start=ref_arb777`
2. При первом `/start` мы записываем: этот Telegram ID → партнёр `arb777`
3. **Все** его пополнения потом дают партнёру **50%**, даже если он пришёл снова без ссылки через полгода

Один юзер = один партнёр (first touch). Self-ref и фрод — clawback.
