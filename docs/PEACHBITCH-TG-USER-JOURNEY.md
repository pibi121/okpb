# PeachBitch TG — путь клиента (пошагово)

**Версия:** v1.0 · 1 сентября 2026

Как я вижу продукт глазами юзера — от первого касания до повторной покупки.

---

## Карта целиком

```
Реклама / канал / реф-ссылка
        ↓
   Канал или сайт /bot
        ↓
      /start в боте
        ↓
   18+ + онбординг
        ↓
   Создать персонажа (3–5 фото)
        ↓
   Лента шаблонов (Mini App)
        ↓
   Выбрать шаблон → оплата (если нет баланса)
        ↓
   Генерация (очередь + ETA)
        ↓
   Результат в чат
        ↓
   Ещё шаблон / пополнить / Peach Studio teaser
```

---

## Шаг 0 — Откуда пришёл

| Канал | Что видит | Что запоминаем |
|-------|-----------|----------------|
| Реф-ссылка арбитражника | `t.me/bot?start=ref_XXX` | `affiliateCode` → 50% с его оборота |
| Свой канал | Пост + кнопка «Открыть бот» | `source=channel` |
| Сайт peachbitch.com/bot | Редирект | `source=web` |
| Сарафан | Прямой `/start` | без рефа |

**Важно:** если бот забанили — юзер идёт в **канал** или на **сайт**, жмёт новую ссылку, `/start` — всё на месте.

## Шаг 3 — Создание персонажа (если ещё нет)

```
Бот: «Загрузи 3–5 фото лица и тела.
      Лучше: анфас, профиль, в полный рост.»

Юзер: [фото] [фото] [фото]

Бот: «Модель «Аня» готова ✅
      Теперь выбери шаблон — подставим её лицо.»

      [🎬 Открыть шаблоны]
```

**Техника:** фото → `Character` + refs в storage. LoRA **не** нужна.

Если персонаж уже есть — шаг пропускается.

## Шаг 4 — Лента шаблонов (Mini App)

Как Reels / TikTok:

```
┌─────────────────────────────────────┐
│  ◀  Шаблоны          Фото | Видео  │
├─────────────────────────────────────┤
│                                     │
│     [autoplay preview video]        │
│                                     │
│     Догги, вид сзади · 197 ₽        │
│     ⏱ ~5 мин                        │
│                                     │
│  [  ❤️   ]    [ ИСПОЛЬЗОВАТЬ ]     │
│                                     │
│         ↓ свайп вниз                │
└─────────────────────────────────────┘
```

Фильтры: Все / Фото / Видео / С речью / POV / Новое

При **«Использовать»**:
1. Mini App закрывается
2. Бот получает `templateId`
3. Проверка: есть персонаж? есть баланс?

## Шаг 5 — Подтверждение и оплата

```
Бот: «Шаблон: Догги, вид сзади
      Модель: Аня
      Стоимость: 197 ₽
      Время: ~3–8 мин

      [✅ Сгенерировать]  [❌ Отмена]»
```

**Если баланса не хватает:**

```
Бот: «Не хватает 197 ₽. Баланс: 50 ₽

      [ 329 ₽ Hot +10% ]
      [ 659 ₽ Fire +20% ]
      [ 109 ₽ Try ]»

      → оплата Stars / crypto
      → зачисление на баланс в ₽
      → возврат к подтверждению
```

**Опционально (видео с речью):**
```
«Что сказать? (или пропустить)»
Юзер: «Привет, я скучала...»
→ уходит в MiniMax prompt как voiceover
```

## Шаг 6 — Генерация

```
Бот: «⏳ Генерирую... Позиция в очереди: 2
      Примерное время: ~4 мин»

      (через 1–2 мин, если очередь двигается)
      «⏳ Ещё ~2 мин...»

      (готово)
      «✅ Готово!»
      [видео / фото]
      [🔄 Ещё раз]  [🎬 Другой шаблон]
```

Юзер может закрыть Telegram — придёт push когда готово.

**Техника:** job в Redis → GPU worker → `sendVideo`/`sendPhoto`.

### Повторный визит (день 2+)

Юзер открывает бота → персонаж **уже есть** → сразу в ленту → 1 тап → генерация.  
**Это главное отличие от конкурентов** — не загружать фото заново.

## Два типа шаблонов — что происходит под капотом

### Фото (54–87 ₽)

```
template.scenePreview + character.refs[0]
        ↓
Krea Identity Edit v1.2 (dual-ref)
        ↓
still → sendPhoto
```

### Видео (142–384 ₽)

```
character.identityPack (до 5 refs)
        +
template.shotsJson + refVideo
        ↓
MiniMax Ref2V (Quick Video)
        ↓
mp4 → sendVideo
```

## Эмоциональная дуга

| Момент | Эмоция | Задача продукта |
|--------|--------|-----------------|
| Реклама | любопытство | крутое превью |
| Первый /start | осторожность | 18+, простота |
| Загрузка фото | усилие | «всего 3 фото, один раз» |
| Лента | восторг | «хочу вот это» |
| Оплата | сомнение | пакеты, не страшная сумма |
| Ожидание | нетерпение | ETA, не тишина |
| Результат | вау / разочарование | reroll, похожий шаблон |
| Повтор | привычка | персонаж уже есть → быстро |

## Метрики по шагам (воронка)

| Шаг | Метрика |
|-----|---------|
| /start | registrations |
| 18+ confirm | confirm_rate |
| Персонаж создан | character_rate |
| Открыл ленту | template_open_rate |
| Нажал «Использовать» | template_select_rate |
| Оплатил | payment_rate |
| Дождался результата | completion_rate |
| 2-я генерация за 7 дней | D7_retention |

Цель месяц 1: **payment_rate ≥ 5%** от регистраций.
