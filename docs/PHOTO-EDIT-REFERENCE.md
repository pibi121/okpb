# Фото по референсу (Flux.2 Klein — Image Edit)

Дата: **2026-08-08**

Отвечает на: «загрузил фото → тот же свет/локация, другое содержание по промпту».

---

## Что это

Встроенный (не облачный) режим **image edit** у уже установленной модели **Flux.2 Klein 9B** (тот же чекпоинт, что и в основном still-пайплайне `still-lora-flux.json`). Не отдельная модель — тот же `flux-2-klein-9b-fp8.safetensors`, просто другой граф: референс-фото кодируется через VAE и подмешивается в conditioning (`ReferenceLatent`), вместо чистого text-to-image с `EmptyFlux2LatentImage`.

Работает как Flux Kontext: держит композицию/свет/ракурс референса, меняет только то, что просишь в промпте.

## Что доустановлено

Не хватало одного VAE-файла именно под режим редактирования (отдельный от обычного `flux2-vae.safetensors`, который стоит для генерации с нуля):

| Файл | Размер | Путь |
|---|---|---|
| `full_encoder_small_decoder.safetensors` | ~238 МБ | `models/vae/` |

Всё остальное (`flux-2-klein-9b-fp8.safetensors`, `qwen_3_8b_fp8mixed.safetensors`) уже было на диске.

## Готовый workflow

| Где | Файл |
|---|---|
| ПК (Desktop) | `flux2_klein_image_edit_READY.json` |
| Сервер Comfy | Workflows → **`flux2_klein_image_edit_READY`** |

В нём два примера-подграфа:
1. **Один референс** (активен по умолчанию) — фото → новая сцена, композиция/свет сохраняются.
2. **Два референса** (отключён, `mode: 4` — но можно включить кликом) — например «персонаж» + «объект», чтобы объединить их в одном кадре (пример из шаблона: «пусть персонаж возьмёт эту сумку двумя руками»).

По умолчанию подставлено ваше последнее фото (`Flux2_dev_00046_.png`) — **замени на своё** в Load Image, если это не то, что нужно.

## Как пользоваться

1. http://127.0.0.1:8188 → Ctrl+F5 → Workflows → `flux2_klein_image_edit_READY`
2. **Load Image** — своё референс-фото
3. В поле prompt (внутри подграфа, дважды клик по ноде чтобы зайти внутрь) — опиши **что изменить**, явно попроси оставить остальное как есть, например:
   > Keep the exact same location, lighting, camera angle and background. Change only: [что именно]. Everything else must stay identical to the reference.
4. Queue. Это одиночное фото, генерится быстро (не видео) — секунды/десятки секунд на 5090.
5. Результат — SaveImage справа.

### Совет по промпту

Модель хорошо держит сцену, если явно перечислить, что **менять**, и отдельно попросить, что **не трогать** (свет, ракурс, фон) — как в примере шаблона:
> "Replace the background with a quiet coastal cliff at overcast sunset... Keep the subject's pose and framing unchanged."

## Ограничение

Это про **фото**, не видео. Для похожей задачи в видео (например, «этот же персонаж, но другая сцена» в движении) используются другие инструменты:
- **MiniMax H3 R2V** — референс-фото + видео + аудио → готовый видеоклип, см. [`MINIMAX-H3.md`](./MINIMAX-H3.md)
- **Wan Remix I2V** — still + движение, см. [`ROADMAP.md`](./ROADMAP.md)
